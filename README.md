# NeuralDeep Music

Клиент Music API neuraldeep (модель ACE-Step 1.5) в одном HTML-файле: генерация трека
по описанию и тексту, прослушивание, квота по ключу, сохранение результата.
Ключ и настройки хранятся в localStorage браузера.

## Архитектура

Один файл, внутри — четыре независимых блока:

- **SettingsStore** — настройки и API-ключ в localStorage; автосохранение формы
  и восстановление при открытии.
- **ApiClient** — запросы к `https://api.<хост>/v1` (`fetch`): квота, очередь, задача,
  генерация, скачивание трека, бесплатные ручки `/music/sample` и `/music/format`;
  разбор ошибок (`detail`, `error.message`, `quota_exceeded`) и всех кодов 400–503.
- **Transport** — доставка запросов: напрямую либо через CORS-прокси (шаблон с `{url}`);
  при блокировке предлагает лаунчер.
- **Bridge** — мост для интерфейса: все операции возвращают `{ok: true, …}` или
  `{ok: false, error, status}` и не бросают исключений наружу.
- **UI** — форма генерации, опрос задачи раз в 2 секунды, плееры готовых треков,
  журнал с таймстампами.

Генерация асинхронная: `POST /music/generate` → `task_id` → поллинг `GET /music/tasks/{id}`
до статуса `succeeded` / `failed` → файл `GET /music/tasks/{id}/result?index=N`.
Документация API: https://hub.neuraldeep.ru/docs#music

## Как пользоваться

1. Откройте `neuraldeep-music.html` двойным кликом.
2. Вставьте API-ключ (`sk-…`, кабинет → https://hub.neuraldeep.ru/app/keys).
3. Нажмите «Скачать лаунчер (.bat)» в блоке «Транспорт запросов» и запустите его —
   откроется окно Chrome/Edge с обходом CORS. Держите .bat рядом с `neuraldeep-music.html`.
   Если Windows заблокировал файл: правый клик → Свойства → ✓ Разблокировать → ОК.
   Альтернатива — кнопка «Скопировать текст лаунчера»: вставьте текст в Блокнот
   и сохраните как .bat, такой файл не блокируется.
4. Опишите стиль и/или текст песни → «Сгенерировать трек» → слушайте и сохраняйте.
