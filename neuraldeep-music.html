Подключение

не проверено
Браузер заблокировал прямой запрос к API (CORS): сервер neuraldeep не отдаёт CORS-заголовки, а Firefox и обычные окна Chrome/Edge такие запросы запрещают. Обход без прокси: скачайте лаунчер кнопкой ниже и запустите — он откроет приложение в изолированном окне Chrome (или Edge) с отключённой проверкой CORS. Запросы пойдут напрямую в API, ключ — только между браузером и neuraldeep.
Транспорт запросов (обход CORS: лаунчер или прокси)
Лаунчер — маленький .bat, который генерирует эта страница. Держите его в той же папке, что и neuraldeep-music.html (путь относительный). Двойной клик: открывается отдельное окно Chrome/Edge с временным профилем и флагом --disable-web-security — CORS обходится, прокси не нужен. Работает в Chrome (проверено) и Edge; Firefox отключать CORS не умеет. Если Windows заблокировал скачанный .bat («These files can't be opened»): правый клик по файлу → Свойства → ✓ Разблокировать → ОК. Или кнопкой «Скопировать текст лаунчера»: вставьте текст в Блокнот и сохраните как .bat — такой файл не блокируется. В окне лаунчера не открывайте посторонние сайты.
Свой прокси за 2 минуты — Cloudflare Worker (бесплатно)
  1. Откройте https://workers.cloudflare.com → Create Worker → Deploy.
  2. «Edit code» → замените содержимое на код ниже → Deploy.
  3. Скопируйте адрес воркера вида https://xxx.yyy.workers.dev.
  4. Вставьте в поле выше: https://xxx.yyy.workers.dev/?url={url}.
  5. Нажмите «Проверить ключ» — в шапке появится квота.
export default {
  async fetch(request) {
    const cors = {
      'Access-Control-Allow-Origin': '*',
      'Access-Control-Allow-Methods': 'GET,POST,OPTIONS',
      'Access-Control-Allow-Headers': request.headers.get('Access-Control-Request-Headers') || '*',
      'Access-Control-Expose-Headers': 'Content-Disposition,Retry-After',
      'Access-Control-Max-Age': '86400',
    };
    if (request.method === 'OPTIONS') return new Response(null, { status: 204, headers: cors });
    const target = new URL(request.url).searchParams.get('url');
    if (!target) return new Response('?url= required', { status: 400, headers: cors });
    const init = { method: request.method, headers: request.headers, redirect: 'follow' };
    if (!['GET', 'HEAD'].includes(request.method)) { init.body = request.body; init.duplex = 'half'; }
    const upstream = await fetch(target, init);
    const headers = new Headers(upstream.headers);
    for (const [k, v] of Object.entries(cors)) headers.set(k, v);
    return new Response(upstream.body, { status: upstream.status, headers });
  },
};
